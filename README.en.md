# Wayfarer Travel Kit / 归途旅装

A content mod for **Minecraft 26.3 / Forge 66** - five material tiers, a fourth dimension, six bosses, five generated structures and a compact power network.

[中文说明](README.md) | Downloads are in the [Releases](../../releases) tab.

## Install

1. Minecraft 26.3 + Forge 66.x + Java 25
2. Drop `wayfarer-26.3-x.y.z.jar` into `.minecraft/mods`
3. Launch - press **R** in game for the recipe book

## Contents

122 items / 32 blocks / 26 mobs / 81 recipes / 6 structures / 4 advancements

- **Tiers**: fireproof wood -> lava -> void -> star -> abyss
- **Dimension**: the Abyss (gateway block, exclusive ores, 2 structures, 1 boss, neutral NPC)
- **Bosses**: six, all summoned from the Summon Altar
- **Machines**: cables, cells, void generator, electric furnace, pipes, auto-crafter, teleporter, multiblock core
- **Utilities**: bestiary, recipe book, ore detector, waypoint shard, backpack, blueprint, energy HUD
- **Commands**: `/sethome` `/home` `/back` `/wayfarer help|locate|bestiary|energy`

## Known limitations

- Firelands biome requires a **new world**
- Nether "lava sea" is lakes, not a separate biome
- Abyss weather is static; its fluid is a gel block
- Most new mobs reuse vanilla geometry (custom models: Ember Wisp, Ash Wraith)
