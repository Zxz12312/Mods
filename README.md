# 归途旅装 (Wayfarer Travel Kit)

面向 Minecraft **26.3** / Forge **66.x** 的冒险向模组：旅装三件套、下界熔岩线与末地虚无线、
比下界合金更强的星辉线、两个 BOSS、两处遗迹、内置配方书与一整套探索辅助。

- modid：`wayfarer`
- 许可证：MIT
- 当前版本：1.16.3
- 前置：Forge 66.0.0 以上，Minecraft 26.3

## 安装

1. 安装 Minecraft 26.3 + Forge 66.1.8（或更高的 66.x）
2. 把 `wayfarer-26.3-<版本>.jar` 放进 `.minecraft/mods`（整合包放对应实例的 mods）
3. 启动游戏

单人、服务器都可以；服务端只要装同一个 jar，客户端装不装都能进服（不装只是看不到自定义贴图与准心信息）。

## 主要玩法

### 旅装三件套
- **旅者之刃**：铁锭 ×2 + 木棍
- **旅者之镐**：铁锭 ×3 + 木棍 ×2
- **归途罗盘**：铁锭 ×4 + 指南针 —— 右键回家，冷却 30 秒

### 指令
| 指令 | 作用 |
|---|---|
| `/sethome` | 把当前位置设为家 |
| `/home` | 传送回家（支持跨维度） |
| `/back` | 回到上次死亡点 |
| `/wayfarer help` | 模组帮助 |
| `/wayfarer locate [village\|temple\|lava_temple]` | 找最近的防火村庄 / 虚空神殿 / 熔岩神庙 |

### 死亡墓碑
死亡时掉落物自动收进墓碑箱子（27 格），聊天栏播报坐标；装不下才按原版掉落。可在配置里关掉。

### 两条材料线 + 一条终局线
- **熔岩线（下界）**：熔岩矿 → 熔岩碎片 → 熔岩锭 → 熔岩工具/盔甲（数值等同钻石，全部抗火；盔甲带抗火与反伤）
- **虚无线（末地）**：虚无矿（只有下界合金镐/虚无镐/星辉镐挖得动）→ 虚无碎片 → 虚无锭 → 虚无工具/盔甲（远超下界合金，虚无镐能挖基岩）
- **星辉线（终局）**：星辉碎片 → 星辉锭 → 星辉工具/盔甲（比虚无更高一档），另有星辉锤（3×3 挖掘）与星辉镰（范围收割）

### 遗迹与 BOSS
- **虚空神殿（末地）**：黑曜石基座 + 虚空块祭坛 + 四座塔柱，4 个虚空宝箱，里面补刷 3 只**遗忘者守卫**
- **熔岩神庙（防火之地）**：黑石塔柱 + 熔岩祭坛，3 个熔岩宝箱
- **遗忘之王**（末地 BOSS，220 血）：双向随机传送，半血召唤遗忘者
- **熔岩巨兽**（350 血）：命中点燃 8 秒，挨打有 35% 概率反燃
- 两个 BOSS 都用**召唤祭坛**召唤：祭坛上放星辉碎片 → 遗忘之王，放熔岩之心 → 熔岩巨兽；带阶段提示与血条

### 环境与生物
- 主世界新增**防火之地**群系（只对新世界生效），里面有防火树与整套防火木制品、防火村庄
- 主世界刷新**火焰僵尸**、**火焰骷髅**，遇水每秒掉 2 点血；火焰生物带火星粒子
- 末地刷新**遗忘者**，掉不稳定的末影珍珠（128 格随机传送，消耗 1 个 + 10 秒冷却）
- 下界新增成片**岩浆湖**

### 工具与便利
- **配方书**：按 `R` 打开，模组/原版两个页签，可搜索、翻页
- **准心信息**：屏幕正上方显示准心对准的方块或生物信息
- **探矿器**：扫描 16 格内的矿石并报数量
- **传送锚石**：右键方块记锚点，右键空气传送
- **扩容背包**：27 格随身储物（右键收纳，潜行右键取出）
- **虚无熔炉**：投虚无能量自动熔炼
- **熔岩辣椒**：抗火 + 饱食
- **火焰商人**：防火村庄的新职业，5 级交易，工作站点是召唤祭坛

## 配置

`config/wayfarer-common.toml`：

| 键 | 默认 | 说明 |
|---|---|---|
| `general.enableGrave` | true | 死亡墓碑开关 |
| `general.lowDurabilityPercent` | 15 | 低耐久提示阈值（%） |
| `general.compassCooldownTicks` | 600 | 归途罗盘冷却（tick） |
| `general.wandCooldownTicks` | 10 | 火焰法杖冷却（tick） |
| `loot.starShardWeight` | 2 | 遗迹宝箱里星辉碎片的权重 |

## 已知限制

- **防火之地只对新世界生效**（覆盖了世界预设 `normal`），老存档仍会刷火焰生物但不会有防火之地地形
- **熔岩海是下界成片岩浆湖**，不是独立群系名：26.3 下界只有 5 个固定气候点，没有插入新群系的空间
- BOSS 音乐用的是原版唱片音轨（Pigstep），不是新增音频文件
- 配方书只做查询，不支持「一键放入材料」

## 构建

源码不随 jar 发布；如需重新构建，见开发目录的 `_dev`（javac 直接对 Forge 26.3 的 jar 编译 + `jar --create` 打包）。
